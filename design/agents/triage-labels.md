# Triage statuses

Record the canonical role directly in the ticket's `Status:` field.

| Status | Meaning |
| --- | --- |
| `needs-triage` | Awaiting maintainer evaluation |
| `needs-info` | Awaiting clarification |
| `ready-for-agent` | Specified and ready for agent implementation |
| `ready-for-human` | Requires human implementation |
| `wontfix` | Will not be implemented |
