# AI Review Council

Independent reviews of a selected code scope, followed by verification and a consolidated report.

## Language

**Reviewer**:
An agent assigned to independently examine the review scope with a particular review type.
_Avoid_: Council member

**Review type**:
The perspective assigned to a reviewer: code, security, or UI/UX.
_Avoid_: Review focus, specialization, review scope

**Review scope**:
The code selected for examination by the reviewers and council agent.
_Avoid_: Review type

**Reviewer report**:
An individual reviewer's assessment, containing findings awaiting verification by the council agent.
_Avoid_: Final report

**Council agent**:
The single agent responsible for verifying reviewer findings and producing the final report.
_Avoid_: Council members, voting panel

**Final report**:
The consolidated assessment produced by the council agent after verifying reviewer findings.
_Avoid_: Reviewer report
