# Domain documentation

This repository uses a single domain context.

- Glossary: [`dev-docs/GLOSSARY.md`](../GLOSSARY.md).
- ADRs: `dev-docs/adr/`.

Read and write both there; `docs/` ships with the app. Read the glossary and the ADRs in the area before exploring.

Use glossary terms in tickets, proposals and tests.
Flag conflicts with existing ADRs explicitly.
